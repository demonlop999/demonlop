## KernelSU WebUI API

The bundled `webroot/app.js` includes the `kernelsu` npm package, version 3.0.2, by weishu. The Android app exposes the compatible `ksu.exec` and `ksu.exit` bridge methods to that UI.

Source: https://github.com/tiann/KernelSU
License: Apache License 2.0 (full text in `LICENSE-kernelsu.txt`)

## AndroidX WebKit

The Android app depends on AndroidX WebKit 1.12.1 for `WebViewAssetLoader`.

Source: https://developer.android.com/jetpack/androidx/releases/webkit
License: Apache License 2.0
